# 考研英语五书合一词汇带背 (kaoyan-vocab5)

**在线使用**：https://jlshdsdk.github.io/kaoyan-vocab5/ （手机/电脑浏览器直接打开，无需安装）

纯静态、零构建、零框架的考研词汇学习站点。词库由五本主流考研词汇书**并集**加工而成（9405 词），以"被几本书同时收录"作为重要性排序依据，配套生词本驱动的 SM-2 间隔复习系统。

## 功能

- **今日学习**：每日新词任务（默认 50 词，可在设置修改），按重要性（★★★★★ → ★）排队。卡片先显示单词+英/美音标+发音，点开后看释义、词组、用法辨析、例句。
- **词库浏览**：按首字母 / 书目 / 重要性 / 关键词筛选；长列表虚拟滚动，点行展开完整词条。
- **生词本（SM-2 复习）**：翻卡四档评分（不认识 0 / 模糊 2 / 认识 4 / 太简单 5），自动排期下次复习时间；间隔 ≥21 天且连对 ≥4 次（或评"太简单"）自动毕业进"已掌握"档案，可复活重学。每词可见复习次数、答对次数、连对、间隔、下次复习日。
- **统计**：连续打卡、每日新增曲线、复习正确率、词库重要性分布。
- **发音**：点按钮即响（英音 en-GB / 美音 en-US，点击 <100ms）。浏览器真人音频可用时自动增强，否则 TTS 合成。
- **数据自持**：未登录时进度存本机浏览器 localStorage；**登录账号后自动云同步**（见下节），换设备登录同一账号自动恢复；设置页仍可一键**导出 / 导入 JSON** 备份。
- **账号与云同步**：邮箱 + 密码注册，每个账号独立进度；管理员（站长）可在 `admin.html` 管理全部账号。
- **深色模式**：跟随系统 + 手动切换；米白纸质浅色主题护眼。

## 数据口径

- **词库**：五书并集 9405 词（去重、屈折变形归并主形后）。
  - `rank`（★1–5）= 该词被几本书收录。★★★★★ = 五本书都收录（767 词），是复习优先级的核心依据。分布：★5=767 / ★4=1062 / ★3=1490 / ★2=3013 / ★1=3073。
  - `books`：每本书的收录记录，含书内单元（Unit/List）与分层（红宝书 必考/基础/超纲、闪过 高频/中频/低频/偶考 等），尽量保留原书信息。
- **例句类型**（诚实标注）：
  - `real 真题`：原书标注了真题年份的例句（当前 1254 条），标注年份出处。
  - `mock 仿写`：真题风格原创句，**绝不谎标为真题**。
  - `dict 词典例句`：书内无年份标注的例句。
- **音标**：优先采用书内印刷音标，缺词由语言模型补全（字段 `src` 标注来源：book / llm / api）。
- **覆盖说明**：各书"书面宣称词数"与实际可抽取词条数存在口径差异（宣传数常含变体与词族），以实测为准；《核心926》实抽主词族头约 490 个、连带拓展词族共 2444 个词条。

五书来源：《考研英语词汇红宝书》《考研核心926词汇及拓展》（石雷鹏）《你还在背单词吗》（刘晓艳）《词汇闪过》《恋练有词：真题词汇6500分层串记》。本站为个人学习用途对词条数据进行了加工改编（去重、合并、规范化、补全），不包含原书排版与原文内容，请支持正版图书。

## 本地运行

无需构建，任选其一：

1. 双击 `index.html` 直接用浏览器打开（推荐 Chrome / Edge）。
2. 或起本地静态服务：`python -m http.server 8000`，访问 `http://localhost:8000/`。

> 注：`file://` 直开时发音的真人音频增强可能受浏览器安全策略限制，TTS 不受影响；建议用本地服务器或在线地址。

## 账号与云同步（部署指引）

账号系统基于 [Supabase](https://supabase.com)（免费额度足够个人站使用）：注册/登录用 Supabase Auth，进度存 Supabase 数据库（每用户一行，行级安全隔离）。**密码在数据库端加密存储，任何人（包括站长）都看不到明文；网页源码里只有公开的 anon key，不泄密。**

首次部署只需做一次（约 5 分钟）：

1. **注册 Supabase**：打开 https://supabase.com → Sign up（用你自己的邮箱）→ 按邮件验证。
2. **建项目**：登录后点「New project」，名字随意（如 `vocab5`），数据库密码点 Generate 并保存，区域选 Singapore（离国内近）。等约 2 分钟初始化。
3. **建表**：左侧「SQL Editor」→ New query。打开仓库里的 `supabase_setup.sql`，**把第 14 行 `admin_email` 引号里的邮箱改成你第 1 步注册用的邮箱**，然后全文复制粘贴到 SQL Editor，点 Run，显示 Success。
   - 用这个邮箱注册的账号自动成为管理员，全站仅此一人；其他邮箱注册的都是普通用户，且普通用户之间进度完全隔离。
4. **取配置**：左侧「Project Settings」→「API」，复制两个值：`Project URL` 和 `anon public` 项目 API key（anon key 是公开密钥，放在前端是设计如此，不是泄密）。
5. **填配置**：把两个值填进 `assets/js/config.js` 的 `SUPABASE_URL` 和 `SUPABASE_ANON_KEY`，提交推送。网站自动启用账号系统。
6. **注册管理员**：打开网站 → 右上角「登录 / 注册」→ 用你的邮箱注册（收确认邮件点链接）→ 登录。顶栏出现 👑 即管理员生效，可进 `admin.html` 管理所有账号（查看进度 / 禁用 / 解禁 / 重置某人数据）。

工作方式：

- 未登录或未配置 Supabase 时，网站与原来完全一样（纯本机 localStorage 模式）。
- 登录后：启动时拉云端进度与本地**词级合并**（记录较新者优先，两台设备学过的词都保留），本机每次改动 3 秒后自动推回云端；换设备登录即恢复。
- 「清空全部学习数据」在登录状态下会同时清空云端，防止进度复活。

## 已知限制

- 云同步为“整份快照推送 + 下次加载词级合并”模式：多设备**同时**在线学习时，后推者覆盖先推者，下次任一设备加载时会按记录新旧自动合并补救；手动从生词本**移除**的词若恰逢当时推送失败，可能在下次合并时复活（再移除一次即可）。主题、每日目标等**设置项不参与合并**，各设备各自保留。
- 未登录时学习进度仍存于**单个浏览器的 localStorage**——清浏览器数据会丢进度，请常用设置页导出备份（登录云同步后无此顾虑）。
- Supabase 免费版项目**连续 7 天无任何 API 请求会被暂停**（站内有人登录使用就不会）；若暂停，去 Supabase 控制台点 Restore 即可，数据不丢。
- GitHub Pages 国内访问可能较慢，可尝试 jsDelivr 镜像：`https://cdn.jsdelivr.net/gh/jlshdsdk/kaoyan-vocab5@main/`（把域名后的部分替换即可）。
- 真人音频增强依赖 dictionaryapi.dev，网络不可达时自动全程 TTS。
- 词条数据由视觉 OCR + 语言模型批量加工，虽经多轮校验抽查，仍可能存在个别错别字或音标误差，欢迎 issue 反馈。
